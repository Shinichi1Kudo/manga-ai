# CHG-20260517-016 人物三视图空手约束与分镜视频无字幕兜底

## 背景

添加人物角色生成三视图时，模型偶尔会让角色手里拿电脑、文件等物品，影响角色设定图的可用性。剧集制作里解析剧本和重新解析后生成分镜视频时，模型也可能把台词错误地做成字幕、标题或画面文字。

## 改动

- 人物三视图文生图提示词增加最高优先级空手约束：双手放松、可见，不得持有任何物品。
- 生成新服装/参考图换装提示词同步增加空手约束，避免换装版本引入手持电脑、文件、手机、书本、包、武器等道具。
- 默认版和详细版剧本分镜解析提示词增加“视频画面文字禁令”，要求对白只能作为剧情/声音信息保留，不得设计成画面字幕。
- 分镜视频生成最终请求增加统一兜底：普通生成和带参考图生成都会在提交模型前追加“禁止字幕、标题、文字贴片、屏幕文字、对白文字、水印”等约束。
- 保留参考图映射标签能力：Seedance 的 `[图1]` 和 Kling Omni 的 `<<<image_1>>>` 仍用于提示词绑定，但约束最终视频画面不能出现可读文字。

## 影响范围

- 添加人物角色时生成三视图。
- 角色生成新服装/换装图。
- 剧集制作中“解析剧本”和“重新解析”生成的分镜描述。
- 分镜视频普通生成、带参考图生成。
