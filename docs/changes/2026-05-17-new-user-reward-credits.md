# CHG-20260517-017 新用户注册赠送 20 积分

## 背景

新用户注册原本赠送 10 积分，注册页礼物条和注册成功提示也展示为 10 积分。现在需要提升为 20 积分，并让注册页展示更显眼。

## 改动

- 后端注册逻辑将新用户初始积分从 10 调整为 20。
- Django 注册成功提示改为“注册成功，已赠送20积分”。
- 注册页礼物条改为“新用户注册即送 20 积分”。
- 加强礼物条视觉权重：提高背景亮度、边框强度、字号和 20 积分数字高亮。
- 新增后端和前端测试，锁定真实发放积分与页面展示一致。

## 影响范围

- 新用户注册接口。
- 注册页展示与注册成功提示。
- 不影响老用户积分余额、兑换码、扣费、返还和积分流水逻辑。

## 验证

- `mvn -Dtest=UserServiceImplTest test`
- `python manage.py test apps.auth.tests`
