# First Render Static Assets Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace browser-generated Tailwind CSS and external first-render dependencies with versioned local assets so every public and authentication page paints with its final layout immediately.

**Architecture:** Add a pinned npm build pipeline that scans Django templates and JavaScript, compiles Tailwind into a committed local stylesheet, and vendors Lucide plus the small Latin Inter variable font. Chinese text uses stable system font fallbacks so the page has no Google Fonts dependency or large CJK font download; all four entry templates load the local stylesheet before body paint and defer the local icon script.

**Tech Stack:** Django templates, Tailwind CSS 3.4.17 CLI, Lucide 0.468.0, Fontsource Inter 5.1.1, Node.js/npm, Django `SimpleTestCase`

---

## File structure

- Create `frontend/package.json`: pinned frontend build commands and dependencies.

- Create `frontend/tailwind.config.js`: template/script scan paths and the existing theme extensions.

```python
from pathlib import Path

from django.conf import settings
from django.test import SimpleTestCase


class SiteStaticAssetTests(SimpleTestCase):
    template_paths = (
        'templates/base.html',
        'templates/auth/login.html',
        'templates/auth/register.html',
        'templates/auth/bind_phone.html',
    )

    def template_source(self, relative_path):
        return (Path(settings.BASE_DIR) / relative_path).read_text(encoding='utf-8')

    def test_entry_templates_load_local_css_before_local_deferred_icons(self):
        for relative_path in self.template_paths:
            with self.subTest(template=relative_path):
                source = self.template_source(relative_path)
                self.assertIn("{% static 'css/site.css' %}", source)
                self.assertIn("{% static 'vendor/lucide/lucide.min.js' %}", source)
                self.assertLess(
                    source.index("{% static 'css/site.css' %}"),
                    source.index("{% static 'vendor/lucide/lucide.min.js' %}"),
                )
                lucide_tag_start = source.rfind(
                    '<script', 0, source.index("{% static 'vendor/lucide/lucide.min.js' %}")
                )
                lucide_tag_end = source.index('>', lucide_tag_start)
                self.assertIn(' defer', source[lucide_tag_start:lucide_tag_end + 1])

    def test_entry_templates_have_no_render_time_external_dependencies(self):
        forbidden = (
            'cdn.tailwindcss.com',
            'fonts.googleapis.com',
            'fonts.gstatic.com',
            'unpkg.com/lucide',
            'tailwind.config =',
        )
        for relative_path in self.template_paths:
            with self.subTest(template=relative_path):
                source = self.template_source(relative_path)
                for marker in forbidden:
                    self.assertNotIn(marker, source)

    def test_compiled_assets_exist_and_contain_critical_layout_rules(self):
        static_root = Path(settings.BASE_DIR) / 'static'
        css = (static_root / 'css/site.css').read_text(encoding='utf-8')
        for marker in ('.fixed', '.flex', '.grid', '.max-w-7xl', '.min-h-screen'):
            self.assertIn(marker, css)
        self.assertIn('@font-face', css)
        self.assertTrue((static_root / 'fonts/inter-latin-variable.woff2').is_file())
        self.assertTrue((static_root / 'vendor/lucide/lucide.min.js').is_file())
```
