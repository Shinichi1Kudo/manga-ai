# 电商带货功能开发设计

## 目标

在现有海带 AI 内容创作平台中新增电商带货工作流。第一版聚焦服装带货，支持用户创建电商系列、创建或上传真人写实模特、在模特下维护多个商品，并基于“模特基础图 + 商品图”直接生成口播种草或试穿展示视频。

## 背景

当前平台已经具备短剧系列、角色资产、角色审核、OSS 上传、图片生成、分镜视频生成、状态轮询和积分流水能力。电商带货需要复用这些底层能力，但业务心智不同：短剧以角色和剧情连续性为核心，电商以模特人格和商品转化为核心。

因此第一版不把商品服装沉淀成角色服装版本。模特是长期资产，商品是挂在模特下的带货资产，每次生成视频时再组合模特图与商品图。

## 范围

第一版包含：

1. 首页“我的系列”按业务分组展示短剧系列和电商系列。
2. 新增电商系列创建流程。
3. 电商系列第一版固定品类为服装，固定视觉风格为真人写实。
4. 电商系列默认画幅为 3:4。
5. 模特支持 AI 生成和上传真人参考图。
6. 模特支持审核、锁定、重新生成基础形象。
7. 商品挂在模特下，一个模特可以维护多个商品。
8. 内容类型只支持口播种草和试穿展示。
9. 试穿展示直接使用模特基础图 + 商品图生成视频，不生成中间试穿图。
10. 底层复用现有图片生成、上传、审核、视频生成、积分和状态轮询能力。

第一版不包含：

1. 不支持电商品类扩展到美妆、食品、数码等。
2. 不支持除真人写实以外的视觉风格。
3. 不支持电商模特的新服装版本管理。
4. 不支持服装 Tab。
5. 不把商品自动转成角色服装资产。
6. 不复用短剧 episode 的剧情式流程。
7. 不做多模特共同带一个商品的协作流程。
8. 不先生成“模特试穿商品图”作为中间资产。

## 产品结构

首页“我的系列”拆成两个分组：

1. 短剧系列：沿用当前系列、角色、剧集、分镜流程。
2. 电商系列：展示电商系列卡片，卡片展示系列名称、模特数量、商品数量、最近生成视频数量和最近更新时间。

工作台入口建议拆成：

1. 创建短剧系列
2. 创建电商系列
3. 剧集制作
4. 电商带货

电商业务主流程：

```text
创建电商系列 -> 创建/上传模特 -> 审核并锁定模特 -> 给模特添加商品 -> 选择商品生成内容 -> 生成视频
```

数据关系：

```text
电商系列 -> 模特 -> 商品 -> 带货分镜/视频任务
```

## 创建电商系列

创建页字段：

| 字段 | 第一版行为 |
| --- | --- |
| 系列名称 | 用户填写，例如“小雅女装种草号” |
| 品类 | 固定为“服装”，页面展示为已选值 |
| 视觉风格 | 固定为“真人写实”，页面展示为已选值 |
| 默认画幅 | 默认 3:4，可让用户选择 |
| 内容类型 | 口播种草、试穿展示，默认都启用 |

画幅选项旁需要展示常用场景：

| 比例 | 常用场景 |
| --- | --- |
| 3:4 | 默认；适合真人模特、服装试穿、商品竖图展示，画面更容易保留人物全身和商品细节 |
| 9:16 | 抖音、快手、视频号等全屏竖屏视频 |
| 1:1 | 商品卡片、头像封面、方图投放素材 |
| 16:9 | 横屏展示、店铺详情素材、电脑端预览 |

第一版默认使用 3:4。若后续视频模型或渠道强依赖 9:16，可以在生成页允许用户覆盖画幅。

## 模特设计

模特是电商带货的长期人物资产。页面和文案统一称为“模特”，底层可以复用现有角色生成和审核能力。

模特字段：

| 字段 | 说明 |
| --- | --- |
| 模特名称 | 只填名字或昵称，例如“小雅”“Ada” |
| 模特来源 | AI 生成、上传真人参考图 |
| 性别/年龄感 | 可选，用于生成和脚本口吻 |
| 身高/体型/尺码 | 可选，但服装试穿建议填写 |
| 气质风格 | 通勤、甜美、轻熟、简约、高级感等 |
| 口播人设 | 亲切真实、专业推荐、直播促单、小红书种草等 |
| 外貌描述 | 用户描述外貌、特点、气质，不写生成三视图话术 |
| 基础形象图 | AI 生成或上传后产生 |
| 状态 | 待审核、已锁定、生成中、生成失败 |

模特名称规则沿用现有角色名称经验：名称只填人名或昵称，职业、身份、风格、体型等都放到结构字段或描述里，避免影响后续资产引用。

上传真人参考图时展示风险提示：真人风格下上传非平台生成的人物图，后续视频生成可能触发真人隐私或素材审核，请确保拥有使用授权，若生成失败可改用 AI 生成模特基础图。

模特能力：

1. AI 生成基础形象。
2. 上传真人参考图。
3. 图片比例裁剪和 OSS 上传。
4. 审核/锁定基础形象。
5. 重新生成基础形象。

模特不提供：

1. 生成新服装。
2. 服装版本 Tab。
3. 商品服装沉淀为模特资产。

## 商品设计

商品挂在模特详情页下，一个模特可以绑定多个商品。商品是可复用的带货对象，但不属于模特服装版本。

商品字段：

| 字段 | 说明 |
| --- | --- |
| 商品名称 | 例如“冰丝防晒衬衫” |
| 商品图片 | 必填，作为视频生成参考图 |
| 商品类型 | 上衣、裤子、裙装、外套、套装、鞋包配饰 |
| 核心卖点 | 显瘦、遮肉、凉感、通勤、百搭、不起皱等 |
| 面料/版型/颜色/尺码 | 可选，帮助生成试穿和口播文案 |
| 适合人群 | 小个子、梨形身材、通勤党、学生党等 |
| 价格/优惠 | 可选，用于口播转化 |
| 试穿要求 | 可选，例如“展示正面、侧面、转身和袖口细节” |
| 状态 | 正常、禁用、删除 |

商品入口放在模特详情页。商品卡片提供两个主要操作：

1. 生成口播
2. 生成试穿

## 内容生成

第一版只支持两个内容类型。

### 口播种草

输入：

1. 模特基础图
2. 商品图
3. 商品字段
4. 模特口播人设
5. 画幅，默认使用系列画幅 3:4

生成目标：

1. 模特出镜讲解商品卖点。
2. 商品可以以手持、旁边展示、画中画或卖点字幕形式出现。
3. 重点是商品痛点、卖点、适合人群、价格优惠和购买理由。

建议默认生成 3 到 5 个轻量分镜，用户可以编辑口播文案和画面描述后生成视频。

### 试穿展示

输入：

1. 模特基础图
2. 商品图
3. 商品字段
4. 试穿要求
5. 画幅，默认使用系列画幅 3:4

生成目标：

1. 直接用模特基础图 + 商品图生成视频。
2. 提示词要求模特穿上商品图中的服装。
3. 分镜覆盖正面展示、侧面展示、转身、细节特写、上身效果。
4. 不生成中间试穿图。
5. 不保存为模特新服装版本。

若后续发现直接生成稳定性不足，再单独设计“临时试穿预览图”能力，但不进入第一版。

## 分镜策略

电商可以复用现有分镜和视频生成能力，但前端心智应更轻。

建议电商生成页展示为“内容脚本”或“视频分镜”，而不是“剧集分镜”。每次从商品卡片发起生成后，系统生成一组 3 到 5 个分镜：

口播种草示例结构：

1. 开场痛点或场景引入。
2. 商品主卖点讲解。
3. 细节展示。
4. 适合人群和穿搭/使用建议。
5. 价格优惠或行动引导。

试穿展示示例结构：

1. 模特穿上商品正面展示。
2. 转身或走动展示版型。
3. 面料、袖口、腰线、下摆等细节。
4. 搭配建议和适合场景。
5. 结束定格展示商品。

用户可以编辑每个分镜的画面描述和口播文案，然后提交视频生成。

## 底层复用边界

可以复用：

1. 图片生成服务。
2. 上传 OSS 和裁剪流程。
3. 角色基础形象的审核/锁定机制。
4. 视频生成服务。
5. 分镜视频状态轮询。
6. 积分扣费和失败返还。
7. 图片和视频历史任务的基础展示能力。

需要独立：

1. 电商系列表或系列类型字段。
2. 电商模特业务语义和页面。
3. 电商商品表。
4. 电商视频任务或电商分镜任务。
5. 电商生成提示词。
6. 首页系列分组查询和展示。

不复用：

1. 短剧 episode 概念。
2. 短剧剧情解析。
3. 角色新服装版本。
4. 服装 Tab。
5. 商品转角色服装资产的流程。

## 错误处理

1. 未锁定模特不能生成视频，提示先审核并锁定模特基础形象。
2. 商品缺少商品图不能生成视频。
3. 试穿展示缺少商品图或模特基础图时禁止提交。
4. 真人参考图触发上游隐私审核时，沿用友好中文错误提示。
5. 视频生成失败时保留项目和分镜，允许用户修改提示词后重试。
6. 积分扣费失败或余额不足时，在提交前提示，不创建生成任务。
7. 生成中任务刷新或新标签页打开后可以恢复状态。

## 测试建议

后端：

1. 创建电商系列时默认品类为服装、视觉风格为真人写实、画幅为 3:4。
2. 模特名称必填且只存名称字段，定位和描述不混入名称。
3. 上传模特参考图可以创建待审核模特基础资产。
4. 商品必须归属于当前用户可访问的模特。
5. 未锁定模特、缺商品图、缺模特图时禁止创建生成项目。
6. 试穿展示请求包含模特图和商品图，但不创建模特服装资产。

前端：

1. 首页“我的系列”分组展示短剧系列和电商系列。
2. 创建电商系列页显示固定品类、固定视觉风格和 3:4 默认画幅。
3. 画幅选项旁展示常用场景说明。
4. 模特创建支持 AI 生成和上传真人参考图两种入口。
5. 模特详情不出现生成新服装入口和服装 Tab。
6. 商品卡片出现生成口播和生成试穿入口。
7. 生成页展示模特图、商品图、内容类型和可编辑分镜。

集成：

1. 从首页创建电商系列到生成口播视频的完整链路。
2. 从上传真人参考图创建模特到生成试穿展示视频的完整链路。
3. 视频生成失败后的错误提示、积分返还和重试。
4. 跨标签或刷新后的生成中状态恢复。

## 后续扩展

后续可以在不破坏第一版结构的前提下扩展：

1. 增加美妆、食品、数码等品类。
2. 增加虚拟真人、3D 模特、动漫国潮等视觉风格。
3. 增加批量商品生成视频。
4. 增加商品库跨模特复用。
5. 增加临时试穿预览图，但仍不沉淀为模特服装版本。
6. 增加渠道模板，例如抖音、小红书、视频号。
7. 增加电商视频数据看板。

## 验收口径

第一版完成后，用户应能完成以下闭环：

1. 在首页看到短剧系列和电商系列分组。
2. 创建一个服装真人写实电商系列，默认画幅为 3:4。
3. 通过 AI 生成或上传真人参考图创建模特。
4. 审核并锁定模特基础形象。
5. 在该模特下添加多个服装商品。
6. 从商品卡片发起口播种草或试穿展示。
7. 系统使用模特基础图和商品图生成轻量分镜。
8. 用户编辑分镜后生成视频。
9. 商品不会变成模特的新服装版本，模特详情不会出现服装 Tab。
